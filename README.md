## Tech Stack
- Frontend: Next.js + Tailwind CSS
- Backend: Node.js + Express
- Database: DynamoDB
- Auth: AWS Cognito
- Storage: S3
- Messaging: SNS + SQS
- Compute: EC2 + ALB + CloudFront + Auto Scaling
- Serverless: Lambda + EventBridge
- Monitoring: CloudWatch
